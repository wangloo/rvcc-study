## 用C代替shell测试脚本

原来的测试之行路径：
1. 字符串传递给rvcc，编译生成汇编文件
2. 汇编文件由交叉编译器编译成二进制
3. QEMU user mode运行这个二进制文件，保存结果
4. 结果和用户传入的excepted对比

更换C之后，测试路径变为：
1. 预处理测试文件，主要是展开宏，多个测试项分类集成在一个测试文件中
2. 将每个测试文件传递给rvcc，编译生成汇编文件
3. 汇编文件由交叉编译器编译成二进制
4. QEMU user mode运行这个二进制文件，在每个测试条目运行结束之后就进行比对

综上来看，时间缩小的根本原因是：多个测试项分类集成到一个测试文件，减少了编译、运行的次数。
